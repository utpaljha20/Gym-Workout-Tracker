# Project Statement

## Project Title
Gym Workout Tracker

## Problem Statement

Gym-goers often record their workout details manually or may find it difficult to keep track of their exercises, weights, sets and repetitions.

The aim of this project is to create a simple Python-based Gym Workout Tracker that allows users to record, store and review their workout information.

## Objectives

- To add and manage exercises.
- To record workout details.
- To store workout data using CSV files.
- To view previous workout records.
- To track progress for an exercise.
- To generate a workout summary.
- To validate user inputs.

## Scope of the Project

The project is designed as a console-based application for basic workout management.

The user can add exercises, record workouts, view workout history, check progress and view overall workout statistics.

## Key Features

1. Exercise Management
2. Workout Recording
3. Workout History
4. Progress Tracking
5. Workout Summary
6. Input Validation
7. CSV Data Storage

## Technologies Used

- Python
- CSV
- VS Code

## Expected Outcome

The application provides a simple way to maintain workout records and obtain basic statistics from the stored workout data.

## Future Enhancements

- Graphical user interface
- Progress charts
- User login and profiles
- Personal record tracking
- More detailed workout analytics
