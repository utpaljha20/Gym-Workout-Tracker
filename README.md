# Gym Workout Tracker

## About the Project

Gym Workout Tracker is a simple Python-based console application that helps users record and manage their gym workouts.

The project allows users to add exercises, record workouts, view workout history, track progress, and view a summary of their workout activities.

## Features

- Add new exercises
- Record workout details
- View workout history
- Track exercise progress
- View workout summary
- View exercise list
- Validate user inputs
- Store data using CSV files

## Technologies Used

- Python
- CSV files
- VS Code
